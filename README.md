# Ecosistema de Automatización IA – Pipeline de Contenidos HITL

Proyecto Final del curso **IA Automation – Coderhouse**.

Este proyecto implementa un ecosistema de automatización para la generación, validación y envío de contenidos mediante inteligencia artificial.

## Tecnologías utilizadas

- **Make** – Orquestación de los flujos de automatización.
- **Airtable** – Base de datos, registro de ejecuciones y Dashboard de Control.
- **Google Gemini AI** – Generación automática de contenidos.
- **Gmail** – Canal de salida para contenidos aprobados.

## Funcionamiento

El ecosistema contempla un flujo de generación automática mediante IA, una instancia de **Human in the Loop (HITL)** antes del envío y rutas de manejo de errores.

Las ejecuciones quedan registradas en Airtable, permitiendo monitorear ejecuciones exitosas, errores y las distintas etapas del proceso.

## Archivos del repositorio

- Blueprint del escenario de **Generación IA y manejo de errores**.
- Blueprint del escenario de **Aprobación HITL y envío por Gmail**.
- **Informe Final del proyecto en PDF**.
- Evidencias técnicas del funcionamiento del ecosistema.
